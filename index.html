In practice

Most of what an agent does should just run. You decide the exceptions.

01

Scope it

Each agent gets its own key and its own write rules, set in the FaultWall app.

02

Let it work

Reads and permitted writes go straight through to Postgres. No agent rewrite.

03

Decide the exceptions

Writes you selected wait for a reviewer. Blocked operations never reach the database.

Try it

Look up the order. Ask before changing it.

Say your support agent can read orders but needs a yes before it changes one. It does the research on its own. The change waits at FaultWall, before it reaches Postgres.
