Why FaultWall

Security and reliability in one binary.

Agent Firewall

An inline L7 proxy between your agents and PostgreSQL. Mission-scoped policies define what each agent can do — allowed tables, blocked operations, row limits.

agent: support-bot
allow: [tickets, customers]
deny: [DROP, TRUNCATE, DELETE]
max_rows: 500
<1ms

Added latency. Queries parsed and checked inline, before they reach Postgres.

Agent Identity

Agents identify via application_name. FaultWall knows who runs what, on every query.

Anomaly Detection

Per-agent statistical baselines. Z-score deviations flagged. No LLM, no API keys.

AI-Native MCP

10-tool MCP server lets agents check their own policies and violations autonomously.
